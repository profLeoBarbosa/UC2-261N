# Lista de Exercícios de JavaScript

---

# 1. Variáveis e Constantes

Crie:
- uma variável `nome`
- uma variável `idade`
- uma constante `PI`

Atribua valores e exiba tudo no console.

---

# 2. Operadores Aritméticos

Utilize `readline-sync` para pedir:
- primeiro número
- segundo número

Realize:
- soma
- subtração
- multiplicação
- divisão
- resto da divisão

Exiba os resultados.

---

# 3. Comparadores e Booleanos

Crie duas variáveis numéricas.

Verifique:
- igualdade
- diferença
- maior que
- menor que
- maior ou igual
- menor ou igual

Exiba os resultados.

---

# 4. Operadores Lógicos

Utilize `readline-sync`.

Peça:
- idade
- se possui carteira

Verifique:
- se a pessoa pode dirigir

---

# 5. Condicionais IF/ELSE

Utilize `readline-sync`.

Peça um número.

Informe:
- positivo
- negativo
- zero

---

# 6. Strings e Protótipos

Utilize `readline-sync`.

Peça um nome completo.

Utilize:
- `toUpperCase()`
- `toLowerCase()`
- `trim()`
- `includes()`
- `replace()`

---

# 7. Arrays Básicos

- adicionar item
- remover item
- mostrar tamanho
- acessar posição específica

---

# 8. Métodos de Arrays

Utilize um array de números.

Use:
- `map()`
- `filter()`
- `find()`
- `includes()`

---

# 9. Funções Simples

Crie uma função `somar` que:
- recebe dois parâmetros
- retorna a soma

---

# 10. Funções com Condicionais

# 11. Laço FOR

Utilize `for` para:
- mostrar números de 1 até 10
- mostrar números pares
- mostrar números ímpares

---

# 12. Laço WHILE

Peça um número.

Utilize `while` para:
- realizar uma contagem regressiva até 0

---

# 13. Arrays com Laços

- `for`

- soma
- média

---

# 14. Funções + Arrays + Condicionais

Exemplo:
